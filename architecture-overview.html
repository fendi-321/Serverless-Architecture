About This Architecture

This project hosts a personal CV/resume website on AWS using a serverless architecture. The static site is served via CloudFront + S3, and a serverless visitor counter built with Lambda + DynamoDB provides real-time page visit tracking. All infrastructure is provisioned and managed through Terraform (IaC).

Request Flow

1 User visits site → DNS resolves to CloudFront
2 Browser loads maffindi.html from S3 via CloudFront
3 JS fetch() → Lambda Function URL
4 Lambda increments count in DynamoDB
5 Returns JSON → Browser displays visitor count

Technology Stack

HTML5 / CSS3 JavaScript (fetch API) Python 3.9 (Lambda) AWS Lambda Amazon DynamoDB Amazon CloudFront Amazon S3 Terraform

Key Features

🌐 Serverless Static Hosting

S3 bucket with CloudFront CDN for low-latency global content delivery. OAC ensures only CloudFront can access the bucket.

📊 Real-time Visitor Counter

Lambda Function URL invoked via JavaScript fetch(). Uses DynamoDB atomic counters for accurate, concurrent-safe increments.

🏗️ Infrastructure as Code

Entire AWS infrastructure defined in Terraform (main.tf) — version-controlled, repeatable, and auditable deployments.

🌙 Dark Mode Support

Built-in dark/light theme toggle with CSS custom properties, persisted in localStorage.

📱 Responsive Design

Mobile-first layout with CSS Grid, flexbox, and media queries for optimal viewing on all screen sizes.

🔒 Security Best Practices

CloudFront OAC (no public S3 access), Lambda execution via Function URL with IAM roles, no hardcoded credentials.

Infrastructure Components (Terraform)

The entire infrastructure is defined in main.tf and provisioned with terraform apply. Resources are created in the ap-southeast-1 (Singapore) region.

Deployment Commands

1. Terraform Init

terraform init

Initializes Terraform, downloads provider plugins for AWS.

2. Terraform Plan

terraform plan

Previews all infrastructure changes before applying.

3. Terraform Apply

terraform apply -auto-approve

Provisions all AWS resources — S3, CloudFront, Lambda, DynamoDB, IAM.
